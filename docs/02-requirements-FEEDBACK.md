#Requirements Feedback

Things to ADD:
- **REQ-905:** System shall allow users to add countries not on current list "on the fly" when submitting Volume numbers.

Things to MODIFY:
- **REQ-211:** System shall allow user to provide reasonable estimates for countries that have legitimate reporting delays.
  Estimates should be clearly marked with a required explanation field
- #### 3.1.3 Regional Grouping should not be restricted to European nations
- **REQ-301:** Regional Grouping should be required for ALL countries, not just European nations
- **REQ-302:** Country mapping to region should be a part of a separate dimension. Coordinators should not
  be required to select Region when entering volumes.
- **BR-206:** Budget submissions required once per year (October) Company is on an October - September Fiscal Year.
 

Things to REMOVE/DEPRIORITIZE:
- **REQ-206:** By their nature, Volumes will always be in whole numbers. Partial (decimal) volumes should not be allowed.

Things I LOVE:
- **REQ-404:** Providing a receipt of successful submission will encourage confidence in the process.  This is not available
  in the current state.
- **REQ-704:** This will be a great reminder to add forecast numbers for new countries that did not have volumes in the budget.
- **REQ-1105:** This is a great idea!
